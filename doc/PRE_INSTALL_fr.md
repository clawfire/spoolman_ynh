Spoolman **n'a pas de système de connexion** : toute personne qui y accède peut lire et modifier votre inventaire. L'accès est donc entièrement géré par les permissions YunoHost, et l'application est privée (tous les utilisateurs YunoHost) par défaut.

Les logiciels d'impression comme Klipper/Moonraker ou OctoPrint ne peuvent pas s'authentifier via le portail YunoHost. Pour en connecter un, consultez la documentation d'administration après l'installation.
