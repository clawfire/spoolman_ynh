Spoolman est un service web auto-hébergé qui suit vos bobines de filament pour imprimante 3D : ce que vous possédez, ce qu'il reste sur chaque bobine, et où elle est utilisée.

### Fonctionnalités

- **Inventaire** : fabricants, filaments (matière, couleur, diamètre, densité, températures…) et bobines individuelles avec leur poids restant
- **Suivi de consommation en direct** : s'intègre à Klipper/Moonraker (Fluidd, Mainsail, KlipperScreen), OctoPrint et Home Assistant, qui remontent la consommation de filament pendant l'impression
- **Base de filaments** : pré-remplit les filaments depuis SpoolmanDB, maintenue par la communauté
- **Étiquettes** : créez et imprimez des étiquettes avec QR code à coller sur vos bobines
- **Champs personnalisés**, interface web multilingue et API REST documentée
- **Mises à jour en temps réel** sur tous les onglets ouverts
