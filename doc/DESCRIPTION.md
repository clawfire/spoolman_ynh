Spoolman is a self-hosted web service that keeps track of your 3D-printer filament spools: what you own, how much is left on each spool, and where it is used.

### Features

- **Inventory**: vendors, filaments (material, colour, diameter, density, temperatures…) and individual spools with their remaining weight
- **Live usage tracking**: integrates with Klipper/Moonraker (Fluidd, Mainsail, KlipperScreen), OctoPrint and Home Assistant, which report filament consumption while printing
- **Filament database**: pre-fills filaments from the community-maintained SpoolmanDB
- **Labels**: design and print QR-code labels to stick on your spools
- **Custom fields**, multi-language web interface and a documented REST API
- **Real-time updates** across every open browser tab
